# 🌼 Daisy Dreams – Flower Boutique Website

**Where Every Flower Tells a Story**

## 📌 About the Project
Daisy Dreams is a beautiful and responsive flower boutique website designed to showcase floral arrangements, introduce boutique services, and provide customers with contact information.

The website offers a simple and attractive interface for exploring flower collections and learning about the boutique.

## ✨ Features
- Attractive homepage with navigation menu
- Flower collections and bouquet showcase
- About section
- Boutique services information
- Google Maps integration for shop location
- Customer reviews section
- Contact form with required-field validation
- Hover effects and interactive styling

## 🛠️ Technologies Used
- HTML5
- CSS3
